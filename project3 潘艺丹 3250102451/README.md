## 2. Start
Please navigate to the code/ directory for detailed compilation and execution instructions.

The program (project.c) is designed to dynamically simulate the greedy choice property of **Dijkstra's algorithm**. Instead of purely calculating the shortest path, it reverse-verifies whether a given permutation sequence of vertices represents a valid execution order. At each step, it checks if the next vertex in the query sequence genuinely holds the minimum distance among all currently unvisited vertices.

The program outputs ***Yes*** if the sequence perfectly aligns with Dijkstra's greedy mechanism, and ***No*** if a sub-optimal vertex is chosen prematurely.
