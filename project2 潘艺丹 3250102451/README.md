## 2. Start

Please navigate to the ***code/*** directory for compilation and execution.
The main algorithm is implemented in ***project2.c*** as a standalone C program.
To verify the program's efficiency and stability under the absolute maximum scale ($O(N_1+N_2)$ time complexity and avoiding Stack Overflow),a local stress test environment is provided in the ***test_folder/***.You can use command-line redirection to feed ***huge_data.txt*** into the compiled ***test.c*** executable and output the results to ***output.txt***.

## 3. Environment Requirements C Compiler: 

- **GCC or any C99** standard compliant compiler.
- **Python Environment**: **Python 3.x** (**only** required if you wish to re-run generate.py to generate new randomized massive test cases).
